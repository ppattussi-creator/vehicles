# vehicles
Final web application

# Descrição do Projeto
Este projeto foi desenvolvido como parte do MBA de Análise de Dados. Seu objetivo é criar e implantar um aplicativo web para realizar uma análise exploratória de um conjunto de dados de anúncios de vendas de carros.

# Funcionalidades
O aplicativo permite criar um histograma com os dados de quilometragem e um gráfico de dispersão, entre preço e quilometragem.
